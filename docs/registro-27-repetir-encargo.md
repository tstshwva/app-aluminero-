# Avance 27 Repetir un encargo

Fecha 10 de noviembre de 2026.

El botón Repetir como nuevo encargo conserva el acabado que seleccionó el cliente cuando sigue disponible. El resumen muestra el acabado de la partida y el flujo solicita revisarlo si el producto ofrece varias opciones y la original ya no se encuentra.

La prueba recorre la selección de acabado, la conversión de 125,5 cm, el envío inicial y la repetición. Comprueba que la segunda solicitud incluye el mismo acabado y la medida, con una clave de operación propia. Pasaron las 40 pruebas JavaScript y las 134 comprobaciones de integración HTTPS y SQL Server.
