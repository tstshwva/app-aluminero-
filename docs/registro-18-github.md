# Avance 18: repositorio del proyecto

Fecha: 5 de noviembre de 2026.

Repositorio de destino autorizado: https://github.com/tstshwva/app-aluminero-
Rama: main.

Se preparó el proyecto completo de JavaScript: apps Cliente y Empresa, paquetes compartidos, API, esquemas de base de datos, scripts, pruebas, documentación y evidencias existentes.

Se excluyen .env, .local, certificados y claves privadas, dependencias descargadas, respaldos de base y artefactos temporales mediante .gitignore. La comprobación previa sobre los 116 archivos iniciales no detectó coincidencias con los secretos configurados ni formatos comunes de claves privadas y tokens. Las 25 pruebas de JavaScript pasaron antes de preparar esta publicación.

AGENTS.md conserva la instrucción del propietario de realizar commit y push al terminar futuros cambios revisados. Esto se aplica al trabajo del agente en este proyecto; no instala un proceso que publique automáticamente cualquier edición externa.

La instalación de SQL Server y los secretos locales no se transfieren con Git. Para otra computadora se deben instalar las herramientas, configurar credenciales propias y ejecutar los scripts documentados. El reinicio y último parche de SQL Server descritos en el registro 17 siguen pendientes.
